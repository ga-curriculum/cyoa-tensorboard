## Foreword
Welcome to Tensorboard! This lesson and pre-recording are meant to get you up to speed on working with Tensorboard, a neural network training dashboard that uses the client-server model.

## Lesson Plan
By the end of this lesson, students should be able to:
* Describe what Tensorboard is and why one might use it
* Run Tensorboard either locally via the server model, or in a notebook using Jupyter magic
